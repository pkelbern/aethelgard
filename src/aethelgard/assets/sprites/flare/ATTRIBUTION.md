# Flare art

Character and monster sprites in this folder are derived from **Flare** (https://github.com/flareteam/flare-game, commit `af6eee6d339ac98011864bfe89da837fe7769c28`), by Clint Bellanger, Justin Jacobs and the Flare contributors listed in `CREDITS-flare-game.txt`.

License: **Creative Commons Attribution-ShareAlike 3.0** (`LICENSE-CC-BY-SA-3.0.txt`). Changes: each frame scaled to 1/3 (192×96 tiles → 64×32) and repacked into one atlas per sheet by `python -m aethelgard.tools.import_flare`. These derived sprites are under the same license.
